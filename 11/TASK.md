# Шаблонизация в Go

В этой практике вам нужно реализовать веб-приложение, которое отображает список товаров. 

## app/solution.go

Это веб-приложение имеет два HTTP-обработчика:

* Обработчик HTTP-запроса `POST /items` сохраняет новый товар в массиве `items []Item`, где `Item` это структура, которая содержит информацию о товаре.

* Обработчик HTTP-запрос `GET /items/view` генерирует HTML-страницу, которая отображает список товаров, сохраненных в оперативной памяти веб-приложения. HTML-страница генерируется на основе шаблона **"./templates/items.tmpl"**.

Шаблон **"./templates/items.tmpl"** выглядит следующим образом:

```html
<!DOCTYPE html>
<html>
<body>

<h1>Список Товаров</h1>

{{ range $item := . }}
<div>
    <h2>{{ $item.Name }}</h2>
    <p>Цена ${{ $item.Price }}</p>
</div>
{{ end }}

</body>
</html>
```

Давайте рассмотрим пример работы этого веб-приложения. Для начала отправляется HTTP-запрос на создание товара:

```bash
curl -X POST -H "Content-Type: application/json" -d '{"name":"Socks","price":100}' http://localhost:8080/items
```

Веб-приложение сохраняет товар в оперативной памяти и возвращает HTTP-ответ со статусом 200 OK:

```bash
HTTP/1.1 200 OK
```

Далее отправляется HTTP-запрос на получение списка товаров:

```bash
curl http://localhost:8080/items/view
```

Веб-приложение генерирует HTML-страницу на основе шаблона **"./templates/items.tmpl"** и возвращает ее в качестве HTTP-ответа со статусом 200 OK:

```bash
HTTP/1.1 200 OK

<!DOCTYPE html>
<html>
<body>

<h1>Список Товаров</h1>

<div>
    <h2>Socks</h2>
    <p>Цена $100</p>
</div>

</body>
</html>
```

Реализуйте HTTP-обработчики в веб-приложении для создания и отображения товаров.
