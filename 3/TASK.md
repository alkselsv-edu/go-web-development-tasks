# Веб-приложение на микрофреймворке Fiber

В этой практике вы можете проверить работу вашего сайта, нажав на кнопку веб-доступ и добавив в путь ссылки строку `convert?from=USD&to=GBP`

## solution.go

Предположим, что вы разрабатываете веб-приложение для конвертации валют. Вам необходимо реализовать обработчик HTTP-запроса `GET /convert`, который будет возвращать курс конвертации в теле HTTP-ответа.

Курсы валют хранятся в глобальной переменной "`exchangeRate"` в виде `map[string]float64`, где ключом является пара валют (например USD/EUR), а значением — курс конвертации.

Пара валют передается в виде двух параметров HTTP-запроса `GET /convert`: `from` и `to`. В значениях параметров может быть указана несуществующая валюта и в этом случае нужно вернуть HTTP-ответ со статусом `404 Not Found`.

Курс конвертации в HTTP-ответе от веб-приложения должен быть в формате числа с двумя знаками после запятой. Для этого используется функция форматирования: `fmt.Sprintf("%.2f", 1.25)`

Пример HTTP-запроса к веб-приложению:

```bash
curl -X GET http://localhost:8000/convert?from=USD&to=EUR
```

Пример ответа:

```bash
HTTP/1.1 200 OK 

0.8
```

### Подсказки

* Fiber под капотом использует [статусы](https://docs.gofiber.io/api/constants) из пакета net/http, потому записи `http.StatusNotFound` и `fiber.StatusNotFound` идентичны
