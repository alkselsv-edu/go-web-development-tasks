# Веб-разработка на Go

## solution.go

Предположим, что вы разрабатываете веб-приложение по обучению программированию. Вам необходимо реализовать обработчик HTTP-запроса `GET /courses/description`, который будет возвращать описание курса в теле HTTP-ответа.
Описания курсов хранятся в глобальной переменной `courses` в виде `map[int64]string`, где ключом является численный идентификатор курса, а значением — описание курса.

Идентификатор курса передается в параметрах HTTP-запроса `GET /courses/description?course_id=` в поле `course_id`.

### Подсказки

* Параметры запроса передаются ввиде строки. Для парсинга строки в число используйте функцию [`strconv.ParseInt()`](https://pkg.go.dev/strconv#ParseInt)
