# HTTP Middleware

## app/solution.go

Представим, что у вас есть написанное веб-приложение с несколькими HTTP-обработчиками. Вам необходимо настроить посредников перед всеми HTTP-обработчиками этого веб-приложения по следующим правилам:

* Каждый входящий HTTP-запрос должен быть залогирован в формате: `69b39a07-fea7-45a1-809d-3f3f1f897068: GET /foo -  200`, где "69b39a07-fea7-45a1-809d-3f3f1f897068" — это уникальный идентификатор запроса; "GET" — это метод HTTP-запроса; "/foo" — это путь HTTP-запроса; "200" — это код HTTP-ответа
* Логирование должно производиться в файл `file`

* Каждый HTTP-обработчик может быть вызван не чаще одного раза в две секунды
