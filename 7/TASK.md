# CRUD-операции в Fiber

В этой практике вам нужно разработать веб-приложение, которое управляет списком задач. Каждая задача может быть создана, отредактирована, просмотрена и удалена. Давайте рассмотрим эти операции более подробно.

## app/solution.go

* Для создания задачи в веб-приложение приходит HTTP-запрос `POST /tasks` с телом в виде `{"description": string, "deadline": unix_timestamp (int64)}`. Веб-приложение присваивает задаче идентификатор и записывает в оперативной памяти. После обработки веб-приложение возвращает HTTP-ответ с кодом *200 OK* и идентификатором в теле: `{"id": int}`

* Для обновления задачи в веб-приложение приходит HTTP-запрос `PATCH /tasks/:id` с телом в виде `{"description": string, "deadline": unix_timestamp (int64)}`. Веб-приложение обновляет задачу в оперативной памяти. Если такой задачи не существует, то возвращается HTTP-ответ с кодом *404 Not Found*. В случае успеха возвращается статус *200 OK*.

* Для чтения задачи в веб-приложение приходит HTTP-запрос `GET /tasks/:id`. Веб-приложение возвращает задачу в теле ответа в виде `{"id": int, "description": string, "deadline": unix_timestamp (int64)}`. Если такой задачи не существует, то возвращается HTTP-ответ с кодом *404 Not Found*.

* Для удаления задачи в веб-приложение приходит HTTP-запрос `DELETE /tasks/:id`. Веб-приложение удаляет задачу из оперативной памяти. Если такой задачи не существует, то возвращается HTTP-ответ с кодом *404 Not Found*. В случае успеха возвращается статус *200 OK*.

Генерация идентификаторов задач происходит с помощью глобальной переменной `taskIDCounter`. При создании новой задачи значение этого счетчика записывается в идентификатор задачи, а затем увеличивается на единицу.

Давайте рассмотрим пример работы с веб-приложением по управлению задачами. Для начала, создадим новую задачу:

```bash
curl -X POST -H "Content-Type: application/json" -d '{"description": "Learn Go", "deadline": 1922258564}' http://localhost:8080/tasks
```

В HTTP-ответе мы получим идентификатор созданной задачи:

```bash
HTTP/1.1 200 OK

{"id": 1}
```

Теперь, давайте обновим описание задачи:

```bash
curl -X PATCH -H "Content-Type: application/json" -d '{"description": "Learn Go and Fiber"}' http://localhost:8080/tasks/1
```

В ответе мы получим статус *200 OK*:

```bash
HTTP/1.1 200 OK
```

Далее попробуем прочесть задачу:

```bash
curl -X GET http://localhost:8080/tasks/1
```

В ответе мы получим обновленную информацию о задаче:

```bash
HTTP/1.1 200 OK

{"id": 1, "description": "Learn Go and Fiber", "deadline": 1922258564}
```

Теперь удалим задачу:

```bash
curl -X DELETE http://localhost:8080/tasks/1
```

В ответе мы получим статус *200 OK*:

```bash
HTTP/1.1 200 OK
```

Это означает, что задача была успешно удалена из оперативной памяти веб-приложения.
